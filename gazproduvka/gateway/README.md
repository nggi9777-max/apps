# ГазПродувка — локальный шлюз PostgreSQL

Браузерная программа `ГазПродувка.html` не подключается к PostgreSQL напрямую и никогда не получает пароль базы. Для режима ONLINE на компьютере запускается небольшой шлюз `gazproduvka-gateway.js`. Он слушает только адрес `127.0.0.1` (снаружи недоступен), хранит пароли в зашифрованном виде и выполняет только параметризованные SELECT-запросы в режиме read-only.

## Требования
- Node.js версии 18 или новее (https://nodejs.org). Дополнительные пакеты (`npm install`) не нужны.
- Учётная запись PostgreSQL с правом только `SELECT` на таблицы или представления измерений (рекомендуется).

## Запуск
- Windows: дважды щёлкните `start-gateway.bat`.
- macOS / Linux: `./start-gateway.sh` или `node gazproduvka-gateway.js`.

В консоли появится адрес `http://127.0.0.1:8765` и **токен**. Токен вводится в программе: «Источники данных» → «ONLINE — PostgreSQL» → поле «Токен шлюза».
Повторно показать токен: `node gazproduvka-gateway.js token`.

## Подключение к базе
1. В программе: «Источники данных» → «Новое подключение» → заполните название, host, port, database, username, schema → «Сохранить подключение».
2. Задайте пароль **в консоли шлюза** (в браузере пароль не вводится):
   ```
   node gazproduvka-gateway.js set-password "Название подключения"
   ```
   Пароль шифруется AES-256-GCM и сохраняется в `secrets.enc`.
   Вместо этого можно использовать стандартный файл паролей PostgreSQL: `%APPDATA%\postgresql\pgpass.conf` (Windows) или `~/.pgpass` (macOS/Linux).
3. «Проверить соединение» → «Определить структуру и сопоставить поля» → выберите таблицу или VIEW, при необходимости добавьте связи (JOIN) с таблицами скважин и месторождений, проверьте автоматическое сопоставление полей → «Сохранить сопоставление».
4. «Подключиться» — загрузка истории за выбранное число суток, затем автоматическое получение только новых и изменённых записей.

## Безопасность
- Пароли не принимаются через HTTP API, не пишутся в журнал `gateway.log` и не хранятся в открытом виде.
- Ключ шифрования — файл `master.key` (права только владельца). Для повышенной защиты задайте ключ через переменную среды `GP_MASTER_KEY` и удалите `master.key`.
- Доступ к API — только с токеном, только с `127.0.0.1`.
- Имена таблиц и столбцов проверяются по фактической структуре базы (`information_schema`); значения передаются только параметрами запроса.
- Сессия переводится в режим `default_transaction_read_only`, ограничение времени запроса — 60 с, объём выборки за запрос — не более 50 000 строк (постранично).
- TLS: режимы `prefer`, `require`, `verify-full`, `disable` (в окне подключения).

## Папка настроек
`%APPDATA%\GazProduvkaGateway` (Windows) или `~/.config/GazProduvkaGateway`. Переопределяется переменной `GP_HOME`; порт — `GP_PORT`.

## Команды
| Команда | Действие |
|---|---|
| `node gazproduvka-gateway.js` | запустить шлюз |
| `node gazproduvka-gateway.js token` | показать токен |
| `node gazproduvka-gateway.js set-password "Имя"` | задать пароль подключения |
| `node gazproduvka-gateway.js clear-password "Имя"` | удалить пароль |
